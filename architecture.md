# Архитектура программной системы интернет-магазина

Программный комплекс спроектирован по многозвенной распределённой архитектуре:

1. Клиентский уровень (Client Presentation Tier):
   - Устройства пользователей (персональные компьютеры, планшеты, смартфоны);
   - Клиентское веб-приложение SPA на React/TypeScript (модули витрины, корзины, чекаута и профиля);
   - Автоматизированное рабочее место менеджера магазина (Admin Dashboard).

2. Уровень бизнес-логики и приложений (Application Tier):
   - Высокопроизводительный обратный прокси-сервер Nginx (SSL/TLS терминация, балансировка нагрузки, сжатие gzip/brotli);
   - Сервер приложений (REST API сервисы: Order Service, Catalog Service, Auth Service);
   - Модуль взаимодействия с внешним платежным шлюзом (Payment Gateway Client).

3. Уровень хранения данных (Data Tier):
   - Реляционная СУБД PostgreSQL 16 (схемы таблиц orders, order_items, users, products, payments);
   - Механизмы транзакционной изоляции и ведение журнала опережающей записи (Write-Ahead Logging, WAL).

4. Уровень внешних интеграций (External Tier):
   - Банковский процессинговый шлюз для обработки онлайн-эквайринга и проверки двухфакторной аутентификации 3D-Secure.

# Техническое задание: Программная система интернет-магазина

1. Требования к пользовательскому интерфейсу:
   - Разработка одностраничного веб-приложения (SPA) с адаптивным интерфейсом для мобильных и десктопных устройств;
   - Интуитивный каталог с фильтрацией по категориям, интерактивная корзина и пошаговая форма оформления заказа.
2. Архитектурные требования к серверной части:
   - Сервер приложений на базе REST API для обработки бизнес-правил и оркестрации транзакций;
   - Интеграция с внешним платежным шлюзом по защищенному протоколу HTTPS/TLS с поддержкой 3D-Secure.
3. Требования к хранению данных:
   - Использование реляционной СУБД PostgreSQL 16 с обеспечением транзакционной целостности (ACID);
   - Хранение сущностей пользователей, товаров, позиций в заказах и журнала аудита транзакций.
4. Требования к качеству и производительности:
   - Время отклика API каталога при 95 перцентиле не должно превышать 200 мс;
   - Обеспечение непрерывной доступности сервиса на уровне 99.9%.

5. Требования к информационной безопасности и аудиту:
   - Криптографическая защита каналов связи с использованием протоколов TLS 1.3;
   - Хранение паролей пользователей в виде криптографических хешей с солью (Argon2 / bcrypt);
   - Логирование всех критических операций оформления заказов и изменения статусов в журнал аудита.

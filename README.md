# Проект: Программная система интернет-магазина «ShopSphere»
**Студент:** Пинчук Богдан, группа 9ИС-445
**Специальность:** 09.02.07 «Информационные системы и программирование»

## Краткое описание проекта
Проект представляет собой распределённую программную систему интернет-магазина с веб-интерфейсом для покупателей, панелью управления для менеджера и интеграцией с внешним банковским платёжным шлюзом.

## Структура репозитория
- `README.md` — общая информация о проекте и авторских правах;
- `analysis.md` — анализ предметной области, акторов и ключевых сценариев;
- `tz.md` — техническое задание и функциональные требования;
- `architecture.md` — многозвенная архитектура программной системы;
- `.gitignore` — файл конфигурации исключений системы контроля версий Git.
